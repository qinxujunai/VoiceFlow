## 少打字，少切换

![VoiceFlow 动态演示](docs/voiceflow-demo.svg)

把光标放进输入框，按 **F2** 开始，说完再按 **F2**。
声音在你的电脑上变成文字，录音与识别不上传。

## 为什么做 VoiceFlow

频繁与 AI 对话时，补充上下文和追问往往比一句指令更长。VoiceFlow 把听写放在当前光标处，减少打字，也减少从转写工具复制文字的步骤。

| 使用时关心什么 | VoiceFlow 的处理方式 |
| --- | --- |
| 需要联网或登录吗？ | 录音与识别在本机运行，安装后可离线听写，无需账户。 |
| 自动粘贴没成功怎么办？ | 先复制终稿再尝试输入；文字保留在剪贴板，可按 Ctrl+V，不恢复旧剪贴板。 |
| 停止时的最后一句会被预览漏掉吗？ | 最终识别覆盖完整停止录音；预览只作反馈，不能覆盖终稿。 |
| 还可以找回结果吗？ | 终稿保存到本地历史；交付失败的录音提供本地恢复入口。 |
| 专有词和格式怎么办？ | 自定义术语与明确纠错；句末标点可按应用设置，代码与终端保留格式。 |

VoiceFlow 专注于快捷键触发的日常输入，不提供会议说话人区分，也不靠云端改写润色。上表描述的是交付机制，不是“绝不出错”的承诺。识别可能出错，部分应用需要手动粘贴；剪贴板之后仍可被其他复制操作替换。

## 安静、可管理的日常工具

黑色胶囊展示录音与文字预览，托盘提供听写、恢复和退出入口。
聊天时省略句号，写作时保留标点。
词典维护常用术语和明确纠错；文字习惯可以按应用设置。
中文、英文和混说的准确性应分别评测；当前没有完整自然语音对照证据，不宣称优于其他产品。[验证与限制](docs/product-quality-standard.md)
