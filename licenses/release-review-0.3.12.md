# VoiceFlow 0.3.12 Windows dependency review

Review date: 2026-11-03. Scope: build 261103.1, source `fb1312c64c7d63940fd6393feee433d82710c1b9`, installer SHA-256 `9495f143a7c4f5da0c43d962d34d70658e35cb9f3756112019af853efa343b27`. This engineering review applies only to those exact artifacts, not to other releases or legal advice.

## Component and redistribution review

The [0.3.9](release-review-0.3.9.md), [0.3.10](release-review-0.3.10.md) and [0.3.11](release-review-0.3.11.md) reviews document original terms and redistribution decisions for the pinned Qt/PySide/Shiboken, pynput, native ASR, models, Python, numerical libraries and Microsoft VC runtime. Between the 0.3.11 source `dfde0e2` and this source, `requirements.lock`, `requirements.txt`, `VoiceFlow.spec`, `installer/` (apart from the generated `version.iss`), `vendor/windows/`, `model-manifest.json`, `LICENSE`, `THIRD_PARTY_NOTICES.md` and every third-party license file are unchanged; `licenses/release-review-0.3.11.md` is the only added license-tree file. This release changes application code, `config.yaml` (hold-to-talk setting) and the built-in dictionary.

Before freezing, the build environment was compared with `requirements.lock`. The local virtual environment had drifted in 15 packages, among them cffi 2.1.1 instead of 2.0.0 and pyinstaller-hooks-contrib 2026.9 instead of 2026.6. A first frozen build was discarded, the locked versions were reinstalled (`pip check` clean, 55 of 55 pins matching), the release gate was rerun and the application was rebuilt. The artifact generator then confirmed that all 18 frozen Python distributions match the lock.

A file-by-file comparison against the signed 0.3.11 provenance finds 494 packaged files. The 0.3.11 record listed 500 because its seven model files had been staged inside the package directory; both installers add the same seven pinned model files from `models/`, and the installed-candidate run checks their sizes and hashes. Only these files differ: the executable; `base_library.zip`, whose container changed while all 155 members are identical; `build-record.json`; `config.yaml`; `knowledge-base/builtin-ai.txt`; `licenses/release-review-0.3.10.md`, whose content is identical apart from CRLF line endings in this checkout; and `numpy-2.5.0.dist-info/INSTALLER` and `RECORD`, which name pip instead of uv as the installing tool while every numpy file is unchanged. `licenses/release-review-0.3.11.md` was added. All 86 DLL/PYD hashes match 0.3.11, the dependency notice manifest is identical, and `THIRD_PARTY_NOTICES.md` keeps SHA-256 `19c3daf6d175ac29019bf3ae6400cc08135011643c6cba4a68a3987265f77038`.

All 57 collected distribution notice files were verified against packaged bytes. sherpa-onnx-core has no separate collected notice; the retained ONNX Runtime MIT terms and upstream third-party notice cover the identical runtime, as in earlier reviews. All packaged files and models are inventoried in the artifact-bound SBOM. Native direct and delay import inspection covered 87 PE files and 758 imports, with zero missing. The native ASR extension and ONNX Runtime keep the 0.3.11 hashes.

Qt/PySide/Shiboken and pynput remain replaceable and dynamically accessible; exact-build frozen Qt Python, Qt native-resource and pynput replacement probes passed in disposable owned copies with the original executable unchanged. These probes establish the tested replacement mechanisms and do not certify a differently built ABI. The five pinned LGPL source archives were checked for size, hash and ZIP integrity; the bundle is byte-identical to the one published with 0.3.9 to 0.3.11 and is attached to this release as `VoiceFlow-0.3.12-LGPL-sources.zip`, SHA-256 `5137f59bab8df5002446cf2a8910b2105eb3eed6876574c09769857f7160e816`. Original attribution, license terms and Microsoft entitlement evidence are retained.

The installer is unsigned. This review makes no claim of a signed installer, pristine consumer machine, macOS availability, or recognition accuracy improvement. The owner dictated with a real microphone on an earlier 0.3.12 development source build, before the review fixes, and directed publication without testing the installed build by hand; no human acceptance of this installer is claimed. Isolated Windows fresh install, 0.3.11 upgrade and uninstall/data-retention were separately verified for this installer.
