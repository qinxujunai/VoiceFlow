# VoiceFlow 0.3.11 Windows dependency review

Review date: 2026-10-28. Scope: build 261028.3, source `dfde0e2bce61f6627acf3e0ef2da4f188245bf6f`, installer SHA-256 `0b200ecb27eead9adba33cc63f53a0360aef497044a5c690bda73e5ca72b241a`. This engineering review applies only to those exact artifacts, not to other releases or legal advice.

## Component and redistribution review

The prior [0.3.9 review](release-review-0.3.9.md) and [0.3.10 review](release-review-0.3.10.md) document original terms and redistribution decisions for the pinned Qt/PySide/Shiboken, pynput, native ASR, models, Python, numerical libraries and Microsoft VC runtime. A file-by-file comparison against the 0.3.10 provenance finds 500 packaged files in each: only the executable, base library archive, build record and dependency notice manifest have changed, and the 4.15.0 typing_extensions notice was replaced by the 4.16.0 notice. All 86 DLL/PYD hashes and all seven bundled model files match; all 155 entries inside base_library.zip match. Frozen distribution records show only typing_extensions changed (4.15.0 to 4.16.0).

The Windows lock includes four changes: anyio 4.15.1 (MIT), certifi 2026.10.23 (MPL-2.0), filelock 4.2.4 (MIT), typing_extensions 4.16.0 (PSF-2.0). Current original license hashes are respectively `5361ac9dc58f2ef5fd2e9b09c68297c17f04950909bbc8023bdb82eacf22c2b0`, `e93716da6b9c0d5a4a1df60fe695b370f0695603d21f6f83f053e42cfc10caf7`, `608c89d5060ae9921adccf3236695bc654a9946e12323ef6c021dfa04e294d48`, and `3b2f81fe21d181c499c59a256c8e1968455b6689d269aa85373bfb6af41da3bf`. Only typing_extensions is collected in the frozen inventory. Wheel requirements introduce no new dependency names; anyio raises the existing typing_extensions version floor. `pip check` passed.

All 57 collected distribution notice files in the generated manifest were verified against packaged bytes. sherpa-onnx-core has no separate collected notice in its metadata; the retained ONNX Runtime MIT terms and upstream third-party notice cover the identical runtime, as documented in the previous review. All packaged files and models are inventoried in the artifact-bound SBOM. Native direct and delay import inspection covered 87 PE files and 758 imports, with zero missing. The new executable was separately checked; matching library hashes alone are not presented as an executable check.

Qt/PySide/Shiboken and pynput remain replaceable and dynamically accessible; exact-build frozen Qt Python, Qt native-resource and pynput replacement probes passed in disposable owned copies. These probes establish the tested replacement mechanisms and do not certify a differently built ABI. The five pinned LGPL source archives were checked for size, hash and ZIP integrity and are distributed with the release as `VoiceFlow-0.3.11-LGPL-sources.zip`, SHA-256 `5137f59bab8df5002446cf2a8910b2105eb3eed6876574c09769857f7160e816`. Original attribution, license terms and Microsoft entitlement evidence are retained.

The installer is unsigned. This review makes no claim of a signed installer, pristine consumer machine, macOS availability, or recognition accuracy improvement. The final user accepted the installed interface; the original three case-specific screenshot records were not all captured and are not reconstructed. Isolated Windows fresh install, 0.3.10 upgrade and uninstall/data-retention were separately verified for this installer.
