# VoiceFlow 0.3.10

## 中文

- 设置采用浅色侧栏、分组卡片、固定保存栏和键帽式快捷键。
- 词典分类与搜索并排显示，内置 AI 术语从 34 项增加到 66 项。
- 历史页简化工具栏、居中空状态，仅在有待恢复内容时显示恢复面板；修复卡片高度与窄窗口元信息换行。
- 胶囊新增文字以 140 ms 淡入，长句开头在边缘渐隐，终稿原地接续或淡入替换；减少动效和高对比度模式保持静态。
- 官网演示显示长句的最新文字；设置页拆分为独立模块，macOS 打包资料归入平台目录。

Windows 10/11 x64，核心听写离线运行。识别引擎和模型权重不变，本版不宣称准确率提升。
安装包未进行 Authenticode 签名，Windows 可能显示安全提示；请核对 Release 的 SHA-256。
macOS 尚无公开下载。

## English

- Settings use a light sidebar, grouped cards, a fixed save bar and keycap shortcuts.
- Dictionary categories and search share one row; the built-in AI vocabulary grows from 34 to 66 entries.
- History has a quieter toolbar, centered empty state and recovery panel shown only when needed. Card sizing and metadata wrapping in narrow windows are corrected.
- New capsule glyphs fade in over 140 ms. Long text fades at the leading edge, and final text replaces the draft in place. Reduced motion and high contrast remain static.
- The website demo shows the latest words in long sentences. Settings pages are separated into modules and macOS packaging files share a platform directory.

Windows 10/11 x64 with offline core dictation. Recognition engines and model weights are unchanged; no accuracy improvement is claimed.
The installer is not Authenticode signed and Windows may show a security prompt. Check the Release SHA-256 before installing.
No public macOS download is available.
