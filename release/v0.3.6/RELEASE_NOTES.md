# VoiceFlow 0.3.6

开口，文字就位。按一下 F2 开始，再按一下完成。VoiceFlow 在你的电脑上离线识别语音，让你继续写邮件、记笔记、回消息。

## 本次更新

- 录音取消与重新开始更稳妥。
- 修复异常退出后后台进程仍在运行的问题。
- 改善听写历史与恢复录音的数据保护。
- 加强手动检查更新时的下载校验。
- 提升界面文字对比度。

官网与项目介绍已同步精简，默认中文，可切换英文。这些介绍页更新不改变本版本安装包。

## 下载

适用于 Windows 10 / 11 x64：[VoiceFlow-0.3.6-Windows-x64.exe](https://github.com/qinxujunai/VoiceFlow/releases/download/v0.3.6/VoiceFlow-0.3.6-Windows-x64.exe)。安装包包含离线识别能力，无需另外安装 Python。

升级保留本机配置、词典和历史。日常启动与听写不联网；需要更新时，在设置中点击“检查更新”。

VoiceFlow is offline dictation for Windows. Press F2 to start, speak, then press again to finish.

This update improves cancellation, process cleanup, local-data protection, update checks and text contrast. The website and project introduction now use concise product copy, with Chinese as the default and an English switch. These page updates do not change the installer.

Windows 10 / 11 x64. Upgrades preserve settings, vocabulary and history. The installer is unsigned; verify it against the attached SHA256SUMS.txt before installation.
