# VoiceFlow 0.3.7

说完，接着写。句末，也按你的习惯来。

## 更新内容

- **文字，更稳妥地回到光标处。** 针对「识别出来，却没有进入输入框」的反馈改进自动输入。没有出现时，按 Ctrl+V 就能接着写。
- **句末，由你选择。** 保留识别标点、省略最后一个句号，或补全句末句号。聊天和写作，各有各的习惯；问号、感叹号和句中标点仍会保留。
- **想法，随时找回。** 听写留在本地历史，方便回看和复制。未完成的录音可以从恢复页继续处理。
- **一枚小胶囊，陪你表达。** 更新听写界面，让正在说的话清楚呈现。

## 使用

把光标放进输入框，按 F2 开始，说完再按 F2。没有自动插入时，按 Ctrl+V 粘贴；终稿可在本地历史中找回。
日常聊天可在设置 → 听写中选择「省略最后一个句号」。

Windows 10 / 11 x64。安装包包含离线模型，不需要 Python。升级前从托盘退出正在运行的 VoiceFlow；安装器不会清除本地配置、词典和听写历史。

## 使用提醒

记事本、Word 和 Notepad++ 已有听写输入验证。部分应用、管理员窗口或输入法状态仍可能需要手动粘贴。
中英混说时，屏幕上的文字可能稍晚出现；请以停止后的结果为准，检查识别内容。

安装包目前未签名，Windows 可能显示安全提示。请从本页下载，并使用随附校验文件核对。
