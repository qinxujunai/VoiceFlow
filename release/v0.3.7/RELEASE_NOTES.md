# VoiceFlow 0.3.7

这次更新围绕两个用户反馈：识别后没有进入输入框，以及聊天时不想带句末句号。

## 更新内容

- 改进停止录音时的目标窗口判断和一次性粘贴路径，减少普通输入窗口被误判为只能复制的情况。
- 设置的「听写」中新增三种句末行为：保留识别标点、省略最后一个句号、补全句末句号。问号、感叹号、省略号、内部标点和明显技术字符串受到保护。
- 停止后使用同一份终稿更新胶囊、剪贴板和历史。不能确认自动插入时，保留「已复制到剪贴板」提示，方便手动粘贴。
- 改善录音恢复、历史操作和后台进程退出；使用更轻量的原生胶囊。

## 使用

把光标放进输入框，按 F2 开始，说完再按 F2。没有自动插入时，按 Ctrl+V 粘贴；终稿可在本地历史中找回。
日常聊天可在设置 → 听写中选择「省略最后一个句号」。

Windows 10 / 11 x64。安装包包含离线模型，不需要 Python。升级前从托盘退出正在运行的 VoiceFlow；安装器不会清除本地配置、词典和听写历史。
