# VoiceFlow 0.3.4

这是一次面向稳定性、升级安全和本地数据控制的 Windows 补丁版本。

发布构建：`build 261001.2`

## 本次更新

- 修复冻结版启动时 Qt 运行库加载失败的问题，避免主机环境中的 ICU 动态库污染发布包。
- “关于 VoiceFlow”增加手动检查更新；只有稳定 Release 同时提供匹配安装包和唯一的 `SHA256SUMS.txt` 校验项时才显示下载链接。
- 历史页增加“清除本机数据”，确认后删除本地听写历史和未交付录音，保留配置、词典和模型。
- README、升级与数据契约、自动化测试和发布验证覆盖同步更新。

## 下载与校验

Windows 10 / 11 x64 用户下载：

`VoiceFlow-0.3.4-Windows-x64.exe`

请使用本 Release 同时附带的 `SHA256SUMS.txt` 校验安装包。官网只会在匹配安装包、校验文件、SBOM 和第三方声明全部存在并通过校验后显示下载入口。

安装包已经包含默认离线模型和双语流式预览模型，安装后无需额外下载模型。升级会保留 `%LOCALAPPDATA%\VoiceFlow` 中的用户数据。

Windows 安装包的代码签名状态以本 Release 的实际资产和发布工作流校验为准；未配置签名证书时 Windows 可能显示安全提示。

---

VoiceFlow 0.3.4 is a Windows patch release for frozen-runtime stability, integrity-first manual updates, and explicit local-data cleanup. The installer, SHA-256 manifest, SBOM, and third-party notices are generated by the tag-driven release workflow and must all be present before the public site exposes the download.
