## 针对反馈的改动

Issue #23 / #19：停止时的前台目标作为粘贴依据，普通输入窗口不因短暂 UIA 未知节点就直接降级为仅复制。只派发一次，目标或剪贴板变化时不继续输入，输入事件派发不冒充插入确认。

Issue #23：设置提供保留识别标点、省略最后一个句号、补全句末句号。保留问号、感叹号、省略号、内部标点及技术字符串；确定性规则，不引入联网润色。

## 保留的限制

原报告应用、权限及控件未知，不能宣称完全复现或彻底解决每种输入状态。
管理员窗口、IME 组合态、焦点竞争及部分控件仍可能需要手动粘贴。
混合语音预览曾达到 6.4 秒间隔，未通过现有 1.3 秒门；未晋升模型或宣称准确率改进。
实际麦克风扬声器回采结果存在差异，其中一次 F2 测试中文终稿仅为 `I.`；后续保留 PCM 的后台回采能量不足，无法据此确证前次根因或自然听写通过。
小时测试缺少终态报告；干净 Windows 10/11 安装生命周期、授权自然 holdout、完整无障碍及安装版网络观察未完成。
原生/静态依赖完整许可审查尚未关闭；随包许可证、源输入与 SBOM 不等同于已审查完毕。

现有安装和用户数据未替换。发布说明保留这些边界；网站保留原有产品演示，描述离线听写、句末偏好和本地历史，帮助细节放入 README。
