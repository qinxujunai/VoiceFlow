# 使用 VoiceFlow

[返回产品首页](../README.md)

## 开始听写

把光标放进输入框，按 **F2** 开始，说完再按 **F2**。
右 Ctrl 和鼠标侧键也可以开始、停止；Esc 取消当前录音，不输出文字。

文字没有自动出现时，按 **Ctrl+V** 粘贴。听写结果也会留在本地历史里，方便回看和复制。
部分应用、管理员窗口或输入法状态需要手动粘贴。
中英混说时，预览可能稍晚出现；请以停止后的结果为准，并检查识别内容。

## 句末，按你的习惯

从托盘打开设置，进入「听写」。你可以选择保留识别标点、省略最后一个句号，或补全句末句号。
聊天不想带句号，可以选择「省略最后一个句号」。问号、感叹号和句中标点仍会保留。
这个设置只调整句末，不会重新改写你的表达。

## 安装与更新

[下载 Windows 版](https://github.com/qinxujunai/VoiceFlow/releases/latest)。需要 Windows 10 / 11 x64 和麦克风。
安装包包含离线听写所需的文件，不需要额外安装 Python。
安装包目前未签名，Windows 可能显示安全提示；请从本项目发布页下载，随包提供 SHA256 校验文件。

升级前，从托盘正常退出 VoiceFlow，然后运行新版安装包。配置、词典和历史会保留。
软件不会自动联网或静默更新；你可以在「关于 VoiceFlow」中主动检查更新。
检查更新只有在安装包与校验文件的版本、摘要相符时，才会提供下载入口。

## 历史与恢复

听写结果保存在本地历史中，可回看、复制或删除。
未完成的录音可从恢复页继续处理。恢复内容可能包含尚未交付的表达，删除前请确认已经不再需要。
「清除本机数据」会在确认后清除听写历史和未交付录音，不会删除配置、词典和模型。

## 隐私与联网

录音和识别都在电脑上完成。日常听写无需联网、不需要账户，也不上传录音。
配置、词典、历史和恢复录音保存在 `%LOCALAPPDATA%\VoiceFlow`。
日常运行不会自动下载模型、检查更新或调用云端识别服务。主动检查更新会访问 GitHub。
源码模式准备依赖或经确认下载模型时需要联网。安装包不包含开发者或其他用户的听写历史。
