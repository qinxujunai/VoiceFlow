## 修复与验证

设置中的「保存标点与格式」在禁用当前聚焦按钮时触发 UI Automation 焦点事件。进程内 Python COM 焦点回调可能与 Qt 主线程相互等待。移除默认 COM 事件订阅，沿用录音期间的后台轮询及停止时的目标复核。

- 原冻结版主线程采样显示 1,467 次停留在保存按钮的 `setEnabled(False)`；保存任务尚未启动。
- 回归用例在旧实现上失败、修复后通过；覆盖预热不订阅 Python COM 回调及主动跟踪继续轮询。
- 修改前后的完整测试均为 796 项通过；版本更新后的复核耗时 67.76 秒。
- doctor 和集成检查通过；冻结包 Qt 边界、原生 ASR 哈希及模型分发决策检查通过。
- 0.3.8 隔离冻结程序进入 ready，音频、最终识别及预览工作进程均 ready；冻结运行诊断退出码为 0。隔离 GUI 启动关闭全局热键。
- 同一修复已在实际安装的 `0.3.7+261011.2` 上点击保存验证。该本地升级保留了 8 项受保护数据的 SHA256；0.3.8 仅推进公开版本与构建编号，没有再次覆盖本地安装。

云端 Windows 测试作业通过；同次安装检查发现自动构建递归复制了模型下载缓存。已将 Windows 检查及发布流程改为只复制安装器使用的六个模型文件，工作流 YAML 解析通过。这个流程修正不改变本次本地安装包；本次本地构建没有递归复制模型目录。修正后的云端安装检查结果需以实际作业结论为准。
