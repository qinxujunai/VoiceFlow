# VoiceFlow 0.3.9

本次候选构建：261012.5。桌面安装包等待再分发许可和完整发布验收；
官网演示与品牌说明可以独立上线，公开下载继续指向已发布的 0.3.8。

## 这次改了什么

- **演示重新流畅起来。** 连续红色波形、平滑扩展的胶囊、逐字文字、
  原位完成后收起。文字保持清晰，不随背景缩放或经过阴影滤镜。
  暂停、离开页面、重播和减少动态效果都有对应行为。
- **后台重新建立视觉层级。** 深色导航、红色选中标记、统一图标、
  白色编辑区和快捷键提示。保留 Windows 原生标题栏，兼容小窗口和系统高对比度。
- **设置只有一个保存入口。** 未改动时禁用；结果在主内容中完整显示。
  保存失败保留草稿并回滚，缺少评测音频不再阻止普通设置保存。
- **词典更容易管理。** 横排词条、搜索、勾选、选中数量、删除所选、撤销、
  分类清空确认和明确的纠错输入。内置术语只读，个人词典仍留在本机。
- **中文碎句和空格整理。** 独立工作进程处理标点，保护原有文字内容，
  异常或超时回退。移除隐藏猜测替换；代码、网址和保留格式输入受到保护。
- **关闭设置继续驻留。** 关闭按钮隐藏设置页，托盘继续提供入口；
  真正退出仍使用托盘“退出”。
- **官网和 GitHub 说清使用价值。** 当前输入框听写、终稿先复制、完整停止录音、
  本地历史和失败恢复都有清楚说明，自动输入受限时仍可手动粘贴。
